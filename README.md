Student Club Attendance Recording System

Overview



A web-based attendance recording system developed to help students record, view, and submit their attendance information for club activities.



Technologies Used

- PHP

- MySQL

- phpMyAdmin

- HTML

- CSS

- JavaScript

Features

Attendance Recording: Allows students to record their attendance for club activities.

Attendance Viewing: Enables students to view their recorded attendance information.

Information Submission: Allows students to submit their attendance-related information through the website.

Database



The system uses MySQL to store attendance records and student information. The database is managed using phpMyAdmin.



How to Run

1. Install XAMPP.

2. Start Apache and MySQL.

3. Copy the project folder into the htdocs directory.

4. Open phpMyAdmin and create a database.

4. Import the provided SQL file into the database. (use file sistem_kehadiran_kelab_catur_smk_dato_bentara_luar.sql)

5. Configure the database connection in the PHP files.



Open the following URL in your browser:



http://localhost/your-folder-name-in-htdocs/



Project Purpose



This project was developed to provide a convenient way for students to manage and submit their club attendance information digitally.
